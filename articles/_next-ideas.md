  - 12月のボーナス

- 出ていく側：家計簿で毎月把握済み

### 家族の前提（記事の数字はここに紐づく）

- **妻は2029年3月31日まで育児休業を取る予定**（＝約2年5ヶ月）

## 次の記事の書き出し（2026-07-28の記事から切り出した2節・そのまま使える）

```markdown
## 役割は変わる。でも、つまらない。

深津さんは別の記事で、この先の役割についても書いている。

https://note.com/fladdict/n/nd42977e5443e

エンジニアは、コードを書く人から、業務をAIが扱える形に翻訳する人へ。
AIと人間の分担や、間違ったときの責任線を設計する側へ。
仕事の場所が、そちらに移っていく。

読んで、そうだろうなと思った。
実際、私がやっていることも、少しずつそっちに寄っている。

ただ、同時にこうも思った。

それ、つまらなくないか。

AIのおかげで、作れる量は増えた。
けれど量が増えただけの日は、終わったあとに何も残らない。

自分が作ったものに、社会的な意味があるかどうか。
その感覚がないまま量だけ吐き出していると、たぶん虚しくなる。

仕事のやりがいは、そこにしかない気がしている。

## 画面の前から、離れてみる

機械化の話に、もう一度戻りたい。

過去の機械化は、人間を肉体労働から解放した。
そして、デスクへ送り出した。

今回はAIが、そのデスクの仕事を引き受けはじめている。

じゃあ、人間はどこへ行くのか。

私の場合は、たぶん身体のほうへ戻るのだと思っている。

現場で人が何に困っているか。
どこで手が止まって、どこで小さく舌打ちしているか。
これはデータに落ちていない。足を運んで、自分の目で見るしかない。

AIが扱えるのは、すでに言葉になったものだけだ。
言葉になる前のものを拾ってくるのは、まだ人間の仕事だと思う。

それに、単純に身体がなまってきた。

エアコンの効いた部屋で、一日中モニターを見ている。
頭も使い切っていないのに、夕方には妙に疲れている。

土に触る。汗をかく。人と対面で話す。
そういう時間を、意識して増やしたいと思うようになった。

逃げなのかもしれない。

ただ、AIを使い倒してきた知見と、現場の身体感覚。
その両方を持っている人は、そんなに多くない気がしている。
```

## 半農半マルチワーカー（2026-07-31 着想）

高坂勝『減速して自由に生きる』を読んで感じたこと。
2026-07-28「AIで作業は減った。仕事は減っていない。」の⑩「画面の前から、離れてみる」の続き。

**軸（案）**：作るコストが下がった分、ボトルネックは「何を作るか」に移った。だから現場に戻る。

**つるにしか書けない部分**
- 元地方公務員 → 行政の仕組みと制約を内側から知っている
- 行政本体はセキュリティ・法規制の壁が高いが、**行政から委託を受けている民間事業者**（福祉法人・介護施設・地域事業者）は民間の速度で動ける
- 報告書作成や行政手続きで消耗している現場の痛みが、経歴的に分かる
- そこに Claude Code / Cursor を持ち込める人は多くない

**進路の選択肢（別のAIとの壁打ちで出た3案）**
1. 現場飛び込み＋自主開発 … 福祉・農業・地域事業者でパート勤務しながら課題を収集し、小さなツールを作って還元
2. 民間IT就職＋副業 … AI活用に理解のある会社で腕を磨き、週末に現場へ関わる
3. 完全マルチワーカー … 週数日の現場作業＋Web/AI請負＋地域活動で、収入源と役割を分散

**書くときの注意**
- 3案はどれも一般論で、つるの制約（第3子出産・家計）が入っていない。そのまま採らない
- 「絶対に真似できない優位性」のような強い断定は使わない。ドメイン経験＋AIの人は他にもいる

## 曖昧な指示、また来た（2026-08-12 受領・施策No.4のCV調査）

現職のディレクターから来た指示。**原文そのまま**（誤字・全角スペースも直さない）。

> 施策一覧の管理NO,4　について　CVが発生していないようで改善したいです。どういう状態か調査をお願いします。

### 分かっていること
施策一覧にテキストリンクがあり、スプレッドシートに飛べる。**何をやった施策なのかは特定できる。**

### 曖昧な4点（記事の骨）
1. **CVの定義** … 何をCVと数えているのか
2. **「発生していない」の根拠** … どの数字を見てゼロだったのか。**計測が動いていない可能性と区別されていない**
3. **期間** … いつからいつまでの話か
4. **「調査」のゴール** … 原因特定なのか、改善案まで出すのか、次の打ち手を決めたいのか

### つるの現状
CVらしき計測が**複数あって、どれを指しているか絞れない**。聞かないと動けない。

### 軸の候補
- **推し：AIには定義を書かないと動かない。人間は、定義を書かずに投げてくる。**
- 次点：「発生していない」を誰も疑っていない。壊れているのは施策ではなく計測かもしれない

### 二度書き注意（[note-learnings.md](../knowledge/note-learnings.md) の「2026-07-24 の差分」より）

- 「丸投げ」も前回の看板。使い回さない
- 今回は**「用語の定義が共有されていない」一点**に寄せる

### `articles/2026-08-12-ai-manager/` との関係
執筆中の記事の節「言葉にできないから、指示にできない」と**鏡像**。
