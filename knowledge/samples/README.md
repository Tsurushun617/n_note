# お手本サンプル集（反響のあった記事）

自分でも納得でき、note上で反響があった記事をここに溜める。
次に記事を書くとき、`write-article` スキルがこの一覧から近いものを選んで参照する。
ルール（`.claude/rules/writing-style.md`）だけでは伝わらない「効くリズム・切り口・余白」を、実物で示すのが目的。

> 教訓（なぜ効いたかの言葉）は `../note-learnings.md`、実物（記事そのもの）はこの `samples/`。

## 運用
- 1記事1ファイル（`YYYY-MM-DD-<slug>.md`）。
- お手本は厳選する（目安5本まで）。増えたら弱いものを外す。
- 取り込み方は「この記事よかった、お手本に追加して」＋ note URL（または本文貼り付け）。
