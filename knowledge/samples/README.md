# お手本サンプル集（反響のあった記事）

自分でも納得でき、note上で反響があった記事をここに溜める。
次に記事を書くとき、`write-article` スキルがこの一覧から近いものを選んで参照する。
ルール（`.claude/rules/writing-style.md`）だけでは伝わらない「効くリズム・切り口・余白」を、実物で示すのが目的。

> 教訓（なぜ効いたかの言葉）は `../note-learnings.md`、実物（記事そのもの）はこの `samples/`。

## 運用
- 1記事1ファイル（`YYYY-MM-DD-<slug>.md`）。
- お手本は厳選する（目安5本まで）。増えたら弱いものを外す。
- 取り込み方は「この記事よかった、お手本に追加して」＋ note URL（または本文貼り付け）。

- 2026-06-25 [最低賃金に追いつかれそう](2026-06-25-minimum-wage.md)（葛藤型）— 数字の落差に自分ツッコミ（「え？」「😭」）を重ねるシュールな息継ぎ。過去記事リンクで回遊を作る。
- 2026-06-30 [不安は的中した](2026-06-30-fuan-tekichu.md)（葛藤型）— 災害メタファーの一貫運用。太字は核心の一文だけ、絵文字で深刻さを中和。批判と理解をセットにし、締めを引用ブロックで独立。
- 2026-07-24 [会社も苦境だが、我が家も苦境。](2026-07-24-kukyou.md)（葛藤型・h2×6）— 対句タイトルで会社の話を自分ごとに。実数（時給1,430円・30万円・2年半）で言い切る。好意を先出ししてから批判へ。締めの固有の比喩は引用ブロックの補足で回収。
- 2025-08-29 [【私の労働観】地方公務員から主夫になり、再就職した話。](2025-08-29-roudoukan.md)（体験型・長編／**要点抜粋**）— 最多反響。タイトルの人生の落差、深い自己開示、損得両面、問い返しの締め。※普段の1,800字とは別モードの勝負長編。
